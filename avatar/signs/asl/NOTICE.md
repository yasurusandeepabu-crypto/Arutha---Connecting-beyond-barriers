# ASL sign data — separate from project MIT code

Source: [Kozha, zhan-a and contributors](https://github.com/zhan-a/Kozha), revision `ce93d533b24740879df1e84cbb5341dfa575fc1f`.

Original files `American_SL_ASL.sigml` and its metadata are preserved unchanged. Per-sign SiGML files are extracted from that dictionary without changing the sign notation. `provenance.json` records source URLs and original SHA-256 hashes.

The upstream metadata specifies **Creative Commons Attribution–NonCommercial 4.0**, with an upstream licensing discrepancy noted there. Treat these data as CC BY-NC 4.0, not MIT. [License terms](https://creativecommons.org/licenses/by-nc/4.0/). ASL-LEX citation: Sehyr, Caselli, Cohen-Goldberg & Emmorey (2021), ASL-LEX 2.0. Upstream describes these as original proof-of-concept encodings informed by that coding scheme.

These 14 signs have **not received Deaf-native review**. Upstream metadata records zero reviewers and identifies unverified parameters and a THANK-YOU edit informed by a BSL entry. Playback does not establish ASL correctness. Our interface labels all output as an unverified ASL lexical preview.
